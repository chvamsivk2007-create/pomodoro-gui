# Pomodoro GUI Timer ⏱️🍅

Python GUI application that implements the **Pomodoro Technique** using the Tkinter library.

---

## 📖 Description
- The Pomodoro Technique is a time management method:
  - 25 minutes of focused work
  - 5 minutes short break
  - After 4 sessions, a longer break
- This app automates the cycle with a clean GUI.

---

## 📂 Features
- Start, reset, and countdown functionality
- Visual timer with labels
- Tracks completed work sessions
- Simple and effective productivity tool
